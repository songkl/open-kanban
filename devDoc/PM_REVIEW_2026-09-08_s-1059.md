# Senior PM 视角审视：Open-Kanban 页面体检报告（s-1059）

> 任务：使用 chrome-devtools-mcp 检查所有页面并以产品经理维度找问题
> 数据快照：30 张关键页面截图（亮 / 暗、移动端、桌面端、设置、Agent、OAuth、任务模态等）
> 评审对象：Open-Kanban 当前主分支前端 Web 应用（含 React 19 + Tailwind）
> 评审方式：逐页走查 → 整理为 P0/P1/P2/P3 问题清单 → 给出改进建议

---

## 1. 一句话结论

Open-Kanban 的**后端能力、看板骨架、任务/活动/设置三大模块的"功能完成度"已经达到商用级**；但前端在**「用户第一眼接触面」**（导航 / 空状态 / 移动端 / 跨页面一致性）上仍有明显缺口**。当前最大的产品价值放大器是：

1. 把"页面之间"补成"产品之间"（全局导航 + 跨页通知）。
2. 把"功能存在但没人能找到"的功能暴露成"Onboarding 引导"。
3. 把"暗黑模式、移动端、深色背景下的可读性"统一打磨一遍。

## 3. 跨页面共性问题（横向梳理）

1. **i18n 不一致**：英文模式下仍然能看到 "管理员"（s1059-09-settings.png）；多个按钮 / 菜单项只有中文 fallback，缺少英文 key
   - 涉及：`userDetail.title` / `settings.admin` / `settings.member` 等
2. **暗色模式覆盖不全**：部分页面（用户详情 / Agent 活动）在暗色模式下出现纯黑底、纯黑前景文字（s1059-22、s1059-19），不是产品调性，更像是 bug
3. **没有任何 Loading / Skeleton**：列表加载是突然出现/消失，**没有 skeleton 占位**，看起来"卡了一下"
4. **没有 EmptyState 行动建议**：所有"暂无 xxx"页面文案都一样："暂无 xxx"，没有引导
5. **拖拽只在桌面端工作**：移动端任务不能拖动 / 不能换列，**移动端完全无法管理看板**
6. **没有全局错误页**：404 / 500 页面没有自定义 fallback
